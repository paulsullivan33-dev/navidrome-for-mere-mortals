METHOD
  The server was exercised over HTTP through both public
  interfaces: the native API (/api, /auth) exactly as the
  web UI uses it, and the Subsonic API (/rest) with real
  salt+token authentication computed by hand. The web UI
  itself was fetched and answered (it identifies v0.64.2)
  but not clicked through; criteria.md records that as a
  documented-only surface. Passwords used in the lab are
  redacted in the transcripts.

  Invented users: ruth (first account = admin) and kenji
  (Kenji Mori, listener). Names, artists, albums and the
  "Specimen" genre are fictional, per series rule 8.

SURPRISES WORTH THE INK
  * The scanner catalogues broken.mp3 (text!) as a track,
    and the streamer returns its bytes with HTTP 200.
  * backup restore refuses an empty data folder:
    "No existing database". Boot once first, then restore.
  * createAdmin is its own endpoint; the user API will not
    create the first user (401 before any user exists).
  * Transcoding defaults to Opus (DefaultDownsamplingFormat).
  * getUser reports playlistRole=false for the admin while
    playlist creation works fine. Protocol archaeology;
    harmless, noted so nobody else chases it.
